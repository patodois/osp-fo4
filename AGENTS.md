# Contributor and agent guide

`fo4-core` provides checked I/O, budgets and manifests; `fo4-archive` reads BA2/BSA;
`fo4-vfs` resolves explicit mounts; `fo4-plugin` reads records, load order and strings;
`fo4-nif`, `fo4-material` and `fo4-texture` read model/material/texture data;
`fo4-scene` assembles scenes and tracks unknowns; `fo4-render` renders on the CPU;
`fo4-unpack` provides the reporting CLI and the `render` example.

Use the [spec index](spec/README.md) for format layouts, sources and hypothesis
status. Record each new format fact with its supporting URL and exact scope.
Announce a new behavior hypothesis, its reason and a falsifiable measurement
before using it; register it in `spec/hypotheses.tsv`. Do not turn an unsupported
assumption into a default. Preserve unknown bytes or return a named error with
source, offset, expected and found values. Keep measured convention separate
from exact floating-point arithmetic.

Allowed sources are public format documentation, schemas such as nifxml and
explicitly authorized measurement data. Do not open or translate third-party
implementations such as nifly, NifSkope, PyNifly, BodySlide, fo76utils, OpenMW,
ByroRedux, OpenFO4, xEdit source/scripts, Mutagen or Material Editor. The existing
attributed MaterialLib layout port is documented in THIRD_PARTY.md; it is not
permission to consult further implementation code. Never inspect game executables
or use decompiled code. Record provenance for every permitted dependency.

Keep game installations read-only. Never commit game assets, textured images,
photographs, executable dumps, private measurements, local machine paths or
secrets. Put local artifacts under ignored `build/` and `reports/`. Do not publish,
push, rewrite history or change visibility unless the user explicitly requests it.
All readers forbid unsafe code; keep checked arithmetic, `try_reserve`, bounded
counts/depth/decompression and exact declared output sizes. Load order and VFS
priority are explicit manifest input. No GPU or UI is needed for this project.

Default verification uses generated bytes, without the game. Keep optional data
replays explicitly ignored with a clear reason. Use at most four Cargo jobs:

```sh
export CARGO_HOME="$PWD/.cargo-home" CARGO_TARGET_DIR="$PWD/target" CARGO_INCREMENTAL=0 RUST_TEST_THREADS=4
cargo test --workspace --offline -j 4
cargo fmt --check
cargo clippy --workspace --all-targets --offline -j 4 -- -D warnings
```
